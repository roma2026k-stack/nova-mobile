# NOVA Mobile 0.1

Мобильное веб-приложение-прототип для публикации через GitHub Pages.

## Что работает
- Один чат с демонстрационными сценариями NOVA.
- Сохранение истории диалога и списка фраз в localStorage браузера.
- Настройка примерного уровня английского.
- Простая проверка слова.
- Экспорт локальной памяти в JSON.
- PWA manifest и service worker для установки/кэширования после публикации по HTTPS.

## Что пока НЕ работает
- Настоящая языковая модель и свободная генерация ответов.
- Синхронизация памяти между устройствами.
- Надёжное серверное хранение.
- Полноценная система интервального повторения и анализ произношения.

## Публикация через iPhone
1. Открой https://github.com/ в Safari и создай бесплатный аккаунт.
2. Создай новый репозиторий с именем `nova-mobile`, выбери Public и включи `Add a README file`.
3. Открой репозиторий → Add file → Upload files.
4. Распакуй ZIP на iPhone в приложении «Файлы». Загрузи `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg` и `README_RU.md` в корень репозитория.
5. Нажми Commit changes.
6. В репозитории открой Settings → Pages.
7. В разделе Build and deployment выбери Deploy from a branch, branch `main`, folder `/ (root)`, затем Save.
8. Подожди публикации. Адрес обычно будет `https://ВАШ-ЛОГИН.github.io/nova-mobile/`.
9. Открой адрес в Safari. Для добавления на экран: кнопка «Поделиться» → «На экран Домой».

Интерфейс PWA и service worker требуют HTTPS, GitHub Pages его предоставляет.

## Важно
Не загружай API-ключи в этот репозиторий. Он публичный. Для подключения настоящей модели потребуется отдельный защищённый серверный посредник или безопасный провайдерский механизм. Бесплатность API и хостинга зависит от текущих условий поставщиков.
